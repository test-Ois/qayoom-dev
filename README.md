# Qayoom.dev

A personal developer hub for projects, experiments, and links.

## Stack

- React + JavaScript (JSX)
- Vite
- CSS3
- No Next.js or TypeScript

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Customize projects

Edit `src/data/projects.js` to add or update projects, categories, stacks, repository links, and live demos.

## Notes

- Project cards support category filters and keyword search.
- The theme toggle switches between dark and light modes.
- GitHub stats are loaded from the public github-readme-stats service and may be unavailable if that third-party service is down.
- Contact is intentionally routed through GitHub; no email address is displayed.
- No deployment is configured by this repository change.
